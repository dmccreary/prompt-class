## How to Use This Interactive Diagram

- **Explore mode** (default): hover over any numbered marker or label to read what that control does.
- **Quiz mode**: click **Quiz**, read the visual hint, and click the matching marker to test yourself.
- **Edit mode**: add `?edit=true` to the URL to drag markers and copy calibrated coordinates.

## Regions Labeled

1. **Update Reminder** — relaunch to load the latest daily build.
2. **Local or Cloud File System** — run against your machine or a cloud VM.
3. **Directory** — the folder this session is scoped to.
4. **Git Branch** — the active branch for the project.
5. **Working Tree** — an isolated Git worktree checkout.
6. **Add Files** — attach files or folders to the context.
7. **Claude Mascot** — a playful animated character.
8. **Account** — your account and sign-in menu.
9. **Plan** — your current subscription plan.
10. **Permissions & Planning** — how much Claude may do without asking.
11. **Voice Dictation** — dictate your request by voice.
12. **Model Selector** — choose which model runs the session.
13. **Effort Level** — how much reasoning effort the model spends.
14. **Resources Remaining Circle** — how much usage allowance is left.
