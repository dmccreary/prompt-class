## How to Use This Interactive Diagram

- **Explore mode** (default): hover over any numbered marker or label to read what that part of the screen does.
- **Quiz mode**: click **Quiz**, read the visual hint, and click the matching marker to test what you remember.
- **Edit mode**: add `?edit=true` to the URL to drag markers and copy calibrated coordinates.

## Regions Labeled

1. **Sidebar Toggle** — collapse or expand the left sidebar.
2. **Search** — search across all of your past conversations.
3. **Cloud / Continuation Badge** — shows when a task can keep running in the cloud.
4. **Home / Code Tabs** — switch between Home (Chat and Cowork) and Claude Code.
5. **New Chat** — start a fresh conversation with clean context.
6. **Projects** — bundle related prompts, files, and instructions.
7. **Scheduled** — the task scheduler for recurring, automated jobs.
8. **Customize** — manage Skills, Connectors, Plugins, and Memory.
9. **Prompt Input** — where you type your prompt (or `/` for Skills).
10. **Chat / Cowork Toggle** — conversation only vs. agentic file work.
11. **Model Selector** — choose the model and reasoning effort.
12. **Voice Dictation** — speak your prompt instead of typing.
13. **Project Directory** — the folder Cowork is allowed to read and write.
14. **Approval Mode** — how often Claude pauses for your approval.
15. **Design (Labs)** — an experimental Labs feature.
16. **Get Apps** — download Claude on your other devices.
